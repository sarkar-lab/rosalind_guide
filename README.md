# rosalind_guide

Practical guides for using the Rosalind HPC cluster in the Sarkar Lab, Lau lab, and Zhou lab.

## Guides

- [Rosalind HPC Server — User Guide](rosalind_hpc_guide.md)  
  Covers system architecture, logging in, conda environments, SLURM job submission, GPU usage policy, storage best practices, job monitoring, and troubleshooting.

- [Running R on Rosalind](running_r.md)  
  Creating a conflict-free conda environment for R, testing it interactively, and running R scripts through Slurm.
